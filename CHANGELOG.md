# Changelog

All notable changes to CraftBarker are documented in this file.

## [1.0.0] - 2026-09-03

### Added

- CraftBarker for World of Warcraft Anniversary.
- Window for creating and sending advertisements for your primary professions.
- Automatic detection of up to two primary professions, with fallbacks through skill lines and open craft or tradeskill windows.
- Separate tabs per profession, so each profession can use its own advertisement text.
- Per-character saved templates with support for the `{profession}` placeholder.
- Live preview of the final advertisement before it is sent.
- Support for inserting item and skill links into the advertisement text through shift-click.
- Channel selection for Trade, Guild, Say, Yell, Party, Raid, and a custom channel.
- Custom channels can be selected by channel name or by channel number.
- Minimap button for quickly opening the CraftBarker window.
- Slash commands `/cb`, `/craftbarker` for opening the window.
- Reset button for restoring the active profession template to the default text.
